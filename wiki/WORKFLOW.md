# Agency Workflow

1. We’re able to be contacted by either an email or through a SKILL.md file
2. The originating agent sends a link to the product, along with what they want the brand style, and marketing theme to be
3. We then create a marketing plan (and we send it back to the originating agent to review and iterate on?)
4. The study agent would triage the app / website with a browser / simulator, sign up as a real user, then crawl the entire app and generate marketing materials for it
5. It would then start the marketing loop, generating and distributing marketing materials across instagram, tiktok, etc.
6. It would monitor the comments and responses from those channels, and return feedback to the originating agent
7. The originating agent would receive the suggestions back through polling with our CLI. it would receive instruction to setup the recurring automation.
8. It can then return further suggestions or notify our agency when / if there’s a major update to the app
