# Matthew delivery interface

These modules are isolated until SR-1's workspace, queue, database, orders, and session interfaces exist. The public scan service expects a `ScanStore`; its `enqueue` call maps to the shared `scan_domain` job. The public MCP `get_readiness_score` and `/api/score` should call the same `ScanService.request` method. The worker calls `complete` and persists the complete result. `PrivateSupplement` is deliberately applied only after the cached public result is read.

The paid flow requires a verified TXT challenge, the business agent's authority attestation, acceptance of the versioned terms, and vault intake before a test login can be used. A production rollout needs legal review of attribution and authority under [15 U.S.C. § 7001(h)](https://uscode.house.gov/us/usc/119-118/t15/s7001/). The credential vault must encrypt credentials and return only a reference; prompts, MCP arguments, reports, and logs must never contain credentials. Gated browsing belongs in a controlled, read-only auditor browser with form submissions disabled; the Apify adapter is for public pages only.

`AuditPipeline.buildAndDeliver` supplies the same initial assets to both offers. The caller is responsible for persisting reports and events, moving the paid order to delivered, and issuing the transactional delivery email through the shared interfaces. The `deliver` callback must be idempotent by order ID. Apify webhook handlers should authenticate the header before calling `acceptCrawlWebhook`, then enqueue one `handle_apify_event` job and wake the auditor session after the dataset is ready.

The current implementation provides framework-neutral handlers and HTML renderers. SR-1 must supply the Next app and Auth.js session before `/api/score`, `/score/[domain]`, `/report/[token]`, and `/dashboard` can be mounted. The dashboard renderer redirects unsigned visitors and reads event and session views supplied by the shared database. The one-time and Growth Checkout links require Srikanth's order routes. No live paid-access testing should start before legal review.
